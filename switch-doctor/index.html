Start from what you're seeing

Don't know which port is the problem yet? Pick the symptom and Switch Doctor will walk you to the cause.

Fault library

Every fault Switch Doctor knows about: what it means, why it happens, and the commands to check it. Commands are Cisco IOS style; most other vendors (Aruba, Juniper, Netgear) have close equivalents.

Import from your real switch

Run show interfaces status on a Cisco-style switch and paste the output below. Switch Doctor maps each port's status, duplex, and speed to a likely fault.

How it reads your output

  • connected: healthy, unless duplex is half (duplex mismatch) or a gigabit port linked at 10/100 (low speed)
  • notconnect: unused if the port has no description, no link if it has one (something's supposed to be there)
  • err-disabled: err-disabled
  • disabled: administratively down
  • inactive: VLAN problem (the VLAN doesn't exist)

After importing, click any port and use Set fault manually to add things the status table can't show, like CRC errors, PoE trouble, or STP blocking.
